# Retail Sales Analysis Using SQl
## project Overview
 This project analyses a sample retail sales dataset using MYSQL to explore sales performance,customer purchases,product categories and revenue trends.
## Tools Used
 - MYSQL
 - MYSQL workbench
 - SQL
 - GitHub
## SQL Skills Demonstrated
 - SELECT and WHERE
 - GROUP BY and ORDER BY
 - Aggregate functions:SUM,COUNT, and AVG
 - DISTINCT
 - Checking missing values and duplicate records
 - UPDATE Statements
 
## Project Objectives

 1. calculate total sales revenue.
 2. Identity revenue generated by different products.
 3. Analyse sales performance across cities.
 4. Examine monthly sales trends.
 5. Identity and standardise inconsistent category names
 6. Check for missing values and duplicate order IDs.
 
## Dataset
 The project uses a fictional retail sales dataset containing 10 sales records.
 ### Project Files
 - `Retail_sales_Analysis.sql` - SQL queries used for cleaning and analysis.
 - `retail_sales_cleaned.csv` - Retail sales dataset.

## Key Business Insights
  - Total sales Revenue : £3,630
  - Total Orders : 10
  - Dataset period : January to March 2025
  - Products Analysed : Laptop , Shoes, Phone ,T-Shirt, Headphones and Jeans
  - Cities Analysed : London, Manchester, Birmingham, Sheffield and Leeds
    
 ## Product Revenue Analysis
  -  Highest Revenue Product : Laptop (£1,700)
  -  Second Highest Revenue product : Phone (£1,400)
  -  Lowest Revenue product : Jeans (£80)
  -  Laptops and Phones together generated approximately 85.4% of totals sales revenue.
